Before you paste
  1. On the team's roster page, switch the view to Grid (sometimes labeled Table), not Card or List.
  2. Select the whole roster table (click-drag or Ctrl/Cmd+A over it) and copy it.
  3. Paste it into the box below, exactly as copied.

*Wrestling works, but the Number column will show weight class, and the third column falls back to class year (Fr./So./Sr.) since there's no "position." Track & field works with the Number column left blank (no jersey numbers), and the third column shows event group (Sprints/Distance/Throws/etc.) instead of a position. Gymnastics has no number and no position, so the Number column is left blank and the third column falls back to class year. Bowling has real jersey numbers but no position, so the third column also falls back to class year. Tennis rosters usually have no number or position at all, so it isn't supported yet — send a sample paste and this can likely be extended.

4Export

Builds a file matching your scheduler template: name, schedule_id, start, end, event_id, task, input_type, input, output_type, output, event_params. schedule_id, event_id, and event_params are left blank so the system assigns them. input_type/output_type are filled in automatically from the task (shadowexport → record_train/profile, clipplayback → clips/dreamcatcher_outputs); start/end are written as full datetimes down to the second. Use Export .xlsx in the bar above if your scheduler expects a workbook, or Export .csv for a plain-text import.
